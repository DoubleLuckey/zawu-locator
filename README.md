# 杂物定位

> 大包套小包，一搜就知道

个人杂物收纳位置管理工具（纯前端 PWA），在线使用：
https://doubleluckey.github.io/zawu-locator/

## 这是什么？

杂物定位是一款帮你记住「东西放在哪」的个人收纳小工具。家里东西多、总翻箱倒柜找不到？
把位置和物品记进来，下次一搜就能找到，不用再满屋找。

## 它都能干什么？

1. **分层记位置，大包套小包也能记**：支持任意层级，比如「储物间 → 纸箱A → 小袋子」，
   一层层记清楚，取物时照着路径找就行。
2. **全局搜索，一搜就找到**：输入物品名、别名、标签或位置名，结果立即列出，并显示完整存放路径。
3. **标签分类，整理更省心**：给物品打标签（如「证件」「充电器」「药品」），同类物品跨位置也能集中查看。
4. **借出登记，不忘还**：东西借给别人时，记下借出人和日期，首页「借出中」一眼就能看到。
5. **照片留证，看脸认出**：重要物品拍张照存进来，找的时候看到照片更容易确认。
6. **数据备份，心里有底**：数据都存在你自己的浏览器里，可随时导出 JSON/CSV 备份，也能从 Excel/CSV 清单批量导入，防止丢失。

## 第一次用，三步上手

1. **新增**：点右下角的「+」按钮，填物品名，并选择它放在哪（比如「储物间 → 纸箱A」）。
2. **搜索**：在顶部搜索框输入物品名或别名，试试「一搜就找到」。
3. **备份**：在「设置」里导出一次备份，数据就有保障了，建议以后定期导出。

## 小提示

- 数据保存在本机浏览器（IndexedDB），不会上传到任何服务器。
- 清理浏览器数据会导致本地数据丢失，请记得先导出备份。
- 支持添加到手机桌面、离线使用，断网也能查。
- 本仓库仅包含示例（Mock）数据，真实数据请通过应用内「设置 → 导入 JSON 备份」或「导入 Excel / CSV 物品清单」导入。

## 开发

技术栈：Vue 3 + Vant 4 + Vite（TypeScript），代码在 `源码/frontend`。

```bash
cd 源码/frontend
pnpm install
pnpm dev      # 本地开发，默认 http://localhost:10086/
pnpm build    # 生产构建
pnpm test     # 单元测试
```
